The following keybinds are as default in the most recent build of Daggerfall Online, and are subject to change. If you notice something on this page is out of date, please open an [issue](https://github.com/tau-samsara/udfop/issues/new?template=content.yml&title=%5BContent%5D%20&page=https%3A%2F%2Ftau-samsara.github.io%2Fudfop%2F%23%2Fguide%2Fcategory%2FContributing). Note that theys keybinds are copied from the general settings menu, mod-specific controls will be listed on their specific mod pages.

## General

**Controller cursor assist**: Defaults to On, makes moving the cursor precisely easier when using analog sticks. 

**Sensitivity**: Defaults to 2.0x, adjust up or down to change how fast the camera moves.

**Invert Up/Down Look**: Defaults to Off, switch to On if you prefer flight simulator type controls.

**Weapon Swing Style**: Defaults to Click or Hold, other options include Click and Gesture.

**Swing Travel Needed**: Defaults to 0.005, increase to make it so you need to move the mouse further in Gesture mode to swing your weapon.

**Draw and Release Bow**: Defaults to Off, set to On to make it so that you can hold your right click button to draw the bow, and release it to fire. Left clicking with an arrow drawn unknocks it so that you can lower the bow without firing.

**Sneak Stays On**: Defaults to Off. Enables toggling sneak mode instead of holding it. Functional, but might be irrelevant due to crouch and sneak being combined [[topic:Crouch]].

**Gradual Start and Stop**: Defaults to Off. Enabling adds acceleration to the start of player movement, and deceleration to the end of player movement. Gives a more weighty feel, but may be disorienting.

**Weapon Hand**: Defaults to Right Hand. Switch to Left Hand if you want weapons to equip to the left hand.

**Game Controller**: Defaults to On. Enables the use of a controller when On.

**Gamepad Look Speed**: Defaults to x1.0. The speed at which the camera will rotate when moving an analog stick.

**Gamepad Cursor Speed**: Defaults to x1.0. Controls the speed at which the cursor moves when using an analog stick in the UI.

**Gamepad Movement Threshold**: Defaults to 90%

**Gamepad Stick Deadzone**: Defaults to 10%. Controls the amount your stick needs to move before input is registered, used to counter stick-drift.
